# =========Banking widget==========


## Banking widget - это backend, который готовит данные для отображения в widget, в личном кабинета клиента крупного банка. Этот виджет показывает несколько последних успешных банковских операций клиента.

## -------------Установка и использование-------------

### **Требования (Requirements):**

1. **Python** версии 3.14.3
2. **Poetry** версия 2.3.2
3. Смотрите файл `pyproject.toml` для получения информации о версиях зависимостях проекта.

### **Установка:**

1. **Клонируйте проект** с этого репозитория, используя в PyCharm (в командной строке терминала) команду:
```
git clone https://github.com/Dmitrii-dev-coder/backend_banking_widget.git
```
2. **Инициализируйте виртуальное окружение** командой:
```
python -m venv <название_окружения>
```
*Например:*
```
python -m venv venv
```
Однако важно убедиться, что у вас корректно настроен путь к Python в системной переменной `PATH`, чтобы команда работала без ошибок. О том, как добавить Python в PATH в Windows 11, смотри [здесь](https://ip-calculator.ru/blog/windows-11/how-to-add-python-to-path-on-windows-11-2/).
3. **Активируйте окружение** с помощью команды:
*   на macOS и Linux:
```
source venv/bin/activate
```
*   на Windows:
```
venv\Scripts\activate
```
*Или используйте `poetry shell` для активации виртуального окружения (доступно только при установленном плагине `poetry-plugin-shell`).*
4. **Установите все зависимости проекта** (указанные в файле `requirements.txt`) командой:
```
pip install -r requirements.txt
```
Также можно установить линтеры на выбор, используя Poetry с помощью команды:
```
poetry add --group lint <линтер>
```
Замените <линтер> на имя нужного линтера, например `flake8` или `mypy`, и они будут указаны в pyproject.toml. 
Если же использовать команду:
```
poetry add <линтер>
```
Тогда линтеры будут установлены для всего PyCharm

## -----------------------Тестирование------------------------
## Примеры тест-кейсов для существующего функционала:

### Модуль masks

#### Функция get_mask_card_number:
1. Тестирование правильности маскирования номера карты.
2. Проверка работы функции на различных входных форматах номеров карт, 
   включая граничные случаи и нестандартные длины номеров.
3. Проверка, что функция корректно обрабатывает входные строки, где 
   отсутствует номер карты.

#### Функция get_mask_account:
1. Тестирование правильности маскирования номера счета.
2. Проверка работы функции с различными форматами и длинами номеров счетов.
3. Проверка, что функция корректно обрабатывает входные данные, где номер счета меньше ожидаемой длины.

### Модуль widget

#### Функция mask_account_card:
1. Тесты для проверки, что функция корректно распознает и применяет 
   нужный тип маскировки в зависимости от типа входных данных (карта или счет).
2. Параметризованные тесты с разными типами карт и счетов для проверки универсальности функции.
3. Тестирование функции на обработку некорректных входных данных и проверка ее устойчивости к ошибкам.

#### Функция get_date:
1. Тестирование правильности преобразования даты.
2. Проверка работы функции на различных входных форматах даты, включая граничные случаи и нестандартные строки с датами.
3. Проверка, что функция корректно обрабатывает входные строки, где отсутствует дата.

### Модуль processing

#### Функция filter_by_state:
1. Тестирование фильтрации списка словарей по заданному статусу state.
2. Проверка работы функции при отсутствии словарей с указанным статусом state в списке.
3. Параметризация тестов для различных возможных значений статуса state.

#### Функция sort_by_date:
1. Тестирование сортировки списка словарей по датам в порядке убывания и возрастания.
2. Проверка корректности сортировки при одинаковых датах.
3. Тесты на работу функции с некорректными или нестандартными форматами дат.

### Общие аспекты тестирования
1. **Фикстуры.** Для всех тестов создайте фикстуры, которые предоставят тестовые данные 
   для списков словарей, включая различные случаи и комбинации state и date.


2. **Покрытие тестами.** Убедитесь, что все ветви кода и исключения, которые могут 
   быть сгенерированы вашими функциями, тестируются.
